# echo-agent semantic baseline

This directory records repository-scoped semantic facts for the complete
`echo-agent` workspace. Ten top-level capability maps cover architecture,
Agent/Turn, Context, Task/Subagent/Workflow, persistence/observation, effects,
extensions, providers, protocols, and quality/evolution. The multilingual SDK
facade remains a protocol child map; SDK identity counts are drift telemetry,
not whole-workspace semantic completion.

`inventory_closure` and `behavior_model_closure` mean that every current path,
known behavior, Finding, and unknown area has a traceable disposition. They do
not mean open Findings are resolved or that the repository has no defects. New
work begins with semantic preflight, maps its first diff, and verifies the
affected boundary before completion.
