# SDK 产品从 Framework workspace 迁出

## 问题

`echo-agent` workspace 同时拥有通用 framework runtime 和已独立推送的 SDK 产品。继续把
SDK package、合同、语言源码和 SDK CI 留在 framework 会让无关 framework 变化承担 SDK
工具链和合同门禁成本，并保留两套产品 ownership。

## 触发条件与影响

迁移目标是删除 framework 中已由 `echo-agent-sdk` 承接的 SDK-owned 路径，同时保留
`asset.framework-acp-adapter`、EventEnvelope、Turn driver 和其它通用运行时 authority。
误删 ACP adapter、learning consumer 或 framework feature 会破坏现有 ACP consumers；
漏删 SDK path 会保留重复 ownership 和 workspace coupling。

`asset.sdk-source-product` 接替，通用 ACP fixture/adapter 由 `asset.framework-acp-adapter`
覆盖，framework learning tests 继续验证保留路径。
